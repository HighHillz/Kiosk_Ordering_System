# Kiosk Ordering System

This project aims to demonstrate how food ordering at restaurants can be automated, completely or almost removing direct interactions between the customer and the staff. This system is designed to be user-friendly for customers while providing powerful management tools for restaurant owners.
This helps in reducing time spent by customers to order food, and make payments more faster and efficient.
